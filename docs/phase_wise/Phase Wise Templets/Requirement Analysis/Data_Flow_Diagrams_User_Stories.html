Data Flow Diagrams & User Stories

1. Introduction

This document presents the Data Flow Diagrams (DFDs) and formal User Stories for the ShopEZ platform. DFDs model the system at two abstraction levels — Context Level (Level 0) and Functional Decomposition (Level 1) — illustrating data flows between actors, processes, and data stores.

2. Level 0 — Context Diagram

flowchart LR
    Customer(["👤 Customer"])
    Admin(["🔑 Administrator"])
    PayGW(["💳 Payment Gateway"])
    Cloudinary(["🖼️ Cloudinary CDN"])
    System{{"🛒 ShopEZ E-commerce System"}}
    Customer -->|"Login Credentials, Search Queries, Cart Actions, Order Details"| System
    System -->|"Product Catalogue, Cart State, Order Confirmations"| Customer
    Admin -->|"Product Data, Category Data, Order Status Updates"| System
    System -->|"Sales Metrics, Order Lists, Platform Reports"| Admin

    PayGW -->|"Payment Success / Failure"| System

flowchart TD

5. User Stories

USNUser TypeUser StoryAcceptance CriteriaPointsSprint
USN-1CustomerAs a customer, I can register by entering my name, email, and password.Account created in DB; redirected to dashboard; duplicate email returns 400.2Sprint 1
USN-2CustomerAs a customer, I can log in using my registered email and password.JWT issued in HTTP-only cookie; incorrect credentials return 401.2Sprint 1
USN-3CustomerAs a customer, I can search and filter products by category, price, and rating.Results accurately reflect filters; update without full page reload.3Sprint 1
USN-4CustomerAs a customer, I can add, remove, and update quantities in my cart.Cart total updates in real time; cart persists across sessions and devices.3Sprint 2
USN-5CustomerAs a customer, I can complete a guided checkout by entering shipping and payment details.All three checkout steps navigable; address validated before proceeding.3Sprint 2
USN-6CustomerAs a customer, I can securely pay via an integrated payment gateway.Payment processed; order status changes to "Paid"; stock deducted; confirmation shown.5Sprint 2
USN-7CustomerAs a customer who has completed a purchase, I can leave a star rating and review.Review appears on the product page; aggregate rating recalculated.2Sprint 3
USN-8AdminAs an admin, I can add, edit, and delete product listings with Cloudinary image uploads.Changes reflect immediately on storefront; images served via CDN URL.3Sprint 1
USN-9AdminAs an admin, I can view all orders and update their delivery status.Status transitions: Processing → Shipped → Delivered; reflected in customer's order history.2Sprint 3
USN-10AdminAs an admin, I can view aggregated sales metrics and monthly revenue charts.Dashboard shows accurate total revenue, order count, and monthly breakdown.3Sprint 3
